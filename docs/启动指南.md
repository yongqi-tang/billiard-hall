# 台球厅预约管理系统 · 启动指南

> 适用场景：把代码拉到一台新电脑后，如何把后端和小程序跑起来。
> 项目根目录：`D:\billiard-hall`（从 GitHub / Gitee 拉下来的就是这个目录）

---

## 一、新电脑需要装的环境

| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | **17** | 后端运行必需 |
| MySQL | **8.x** | 数据库 |
| 微信开发者工具 | 最新稳定版 | 跑小程序 |
| （可选）Maven | 3.6+ | 仅重新打包时需要，直接跑 jar 可不用 |

> `D:\billiard-hall` 已包含打包好的 `backend\target\billiard-hall-backend-1.0.0.jar`，
> **新电脑上不需要 Maven 也能启动后端**。

---

## 二、启动后端（先数据库 → 再后端）

### 第 1 步：建数据库

打开 MySQL 命令行（或 Navicat / DataGrip）执行：

```sql
CREATE DATABASE billiard DEFAULT CHARACTER SET utf8mb4;
USE billiard;
```

然后执行建表脚本（含所有表 + 测试数据）：

```bash
mysql -uroot -p<你的密码> < D:\billiard-hall\backend\sql\schema.sql
```

或用 Navicat / DataGrip 打开 `backend/sql/schema.sql` 直接运行。

### 第 2 步：改数据库账号密码（必须！）

打开 `D:\billiard-hall\backend\src\main\resources\application.yml`，把
`spring.datasource` 下的账号密码改成你自己 MySQL 的：

```yaml
datasource:
  driver-class-name: com.mysql.cj.jdbc.Driver
  url: jdbc:mysql://localhost:3306/billiard?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
  username: root
  password: "改成你的MySQL密码"
```

> 不想改文件的话，启动时用参数覆盖即可（见第 3 步方式 A）。

### 第 3 步：启动后端（二选一）

**方式 A — 直接跑已打包的 jar（推荐，无需 Maven）：**

```bash
java -jar D:\billiard-hall\backend\target\billiard-hall-backend-1.0.0.jar
```

密码没改文件时用参数覆盖：

```bash
java -jar D:\billiard-hall\backend\target\billiard-hall-backend-1.0.0.jar --spring.datasource.password=你的密码
```

**方式 B — 重新打包再跑（改了代码时）：**

```bash
cd D:\billiard-hall
mvn -f backend/pom.xml package -DskipTests
java -jar backend/target/billiard-hall-backend-1.0.0.jar
```

### 第 4 步：验证后端启动成功

启动后看到 `Started BilliardHallApplication` 即成功，浏览器访问：

```
http://localhost:8080/api/table/list
```

能看到球台 JSON 数据即后端正常。管理后台直接访问：

```
http://localhost:8080/admin/index.html
```

账号 `admin` / `admin123`。

## 三、微信小程序操作

1. 打开**微信开发者工具** → 导入项目 → 选择目录 `D:\billiard-hall\miniprogram`
   （选 `miniprogram` 文件夹，里面有 `project.config.json`）
2. AppID 填自己的（没有可用"测试号"）
3. 右上角 **详情 → 本地设置 → 勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
   （后端是 http://localhost:8080，本地调试必须勾）
4. 点 **编译**，打开首页（球台列表）
5. 首次使用会模拟微信登录（自动生成 openid），然后可：
   - 首页点球台 → **在线预约**（选日期 / 时段）
   - 或点 **扫码开台** → 模拟扫码输入 `table://1`（球台ID）→ 开台开始计时
   - 进行中球局页：实时计时 / 续时 / 结账

> 小程序后端地址在 `miniprogram/miniprogram/utils/api.js` 里的 `BASE_URL`，
> 默认 `http://localhost:8080`。若小程序和电脑不是同一台，改成电脑局域网 IP，如 `http://192.168.x.x:8080`。

---

## 四、验证一条完整流程

后端 + 小程序都启动后，走一遍确认系统正常：

1. 小程序首页看到球台列表（空闲 / 使用中状态）
2. 预约一个球台 → 状态变"已预约"
3. 模拟扫码开台 → 自动核销预约、开始计时
4. "进行中"页看计时和费用 → 结账 → 球台恢复空闲
5. 管理后台刷新，能看到这笔订单和营收变化

## 五、常见问题

| 现象 | 解决方法 |
|------|----------|
| 启动报 MySQL 连接失败 | 确认 MySQL 已启动、密码改对、`billiard` 库已建 |
| 端口 8080 被占用 | 启动命令加 `--server.port=8081`，小程序 `api.js` 的 BASE_URL 同步改 |
| 小程序报"不在合法域名列表" | 没勾「不校验合法域名」（三、3 步） |
| 编译报错缺依赖 | 在用 Maven 打包，需配国内镜像（阿里云），否则下载慢/失败 |
| 管理后台打不开 | 后端没启动，或直接访问 `/admin/index.html` 前先确认后端在 8080 端口 |

## 六、项目结构速览

```
billiard-hall/
├── backend/            # Spring Boot 后端（Java 17 + MyBatis-Plus + MySQL）
│   ├── sql/schema.sql  # 建库建表脚本（用户/球台/预约/订单/流水/设备 + 测试数据）
│   └── src/main/resources/application.yml  # 数据库账号密码、计费规则、微信配置
├── miniprogram/        # 微信小程序用户端（含预约 / 扫码开台 / 计时 / 结账页面）
├── admin-web/          # 管理后台（单 HTML，已内嵌到后端 /admin/index.html）
├── test/               # 自动化测试（Node 可跑）
└── docs/               # 开题报告、答辩 PPT、预问答等文档
```
